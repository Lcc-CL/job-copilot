# 个性化求职策略（模板）

> 复制为 `profile.md` 后填写。`profile.md` 含个人数据，已被 .gitignore 排除，不会入库。
> 所有求职 skills（招呼语、简历定制、面试准备、offer 谈判）都会读取本文件作为叙事依据。

## 画像
- 意向：<目标岗位，如 “数据分析师 / 商业分析” @ 城市>
- 薪资：<期望区间，建议先跑 `market` 命令用市场分位数校准>
- 背景：<一句话概括你的转行/晋升/平移处境>

## 求职叙事（招呼语/简历/面试的统一锚点）
- 差异化：<你和同档候选人最不一样的一点，必须有真实证据支撑>
- 证据链：<2~3 条最有说服力的真实经历+量化成果（来自母版简历，不得虚构）>
- 定位话术：<如何一句话解释你的短板（转行/空窗/年限），并给出正在补齐的证据>

## 谈判底线
- 月薪下限：<与 config.toml [me].salary_expect_min 保持一致>
- 不可让步条款：<如 试用期时长/薪资折扣、五险一金基数、竞业限制范围>
