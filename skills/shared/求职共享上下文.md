## 评分系统（Block A-F → 1-5 综合分）

| 维度 | 衡量内容 |
|---|---|
| 简历匹配度 | 技能、经验与量化成果的匹配度 |
| 职业方向契合度 | 职位与候选人目标方向（config `[me].keywords`）的契合 |
| 薪酬竞争力 | 与市场水准对比（5=顶尖, 1=远低于市场） |
| 文化信号 | 公司文化、成长性、稳定性、加班/考勤政策 |
| 红线警告 | 风险扣分项（负向调整） |
| **综合评分** | 加权平均 |

**决策阈值**：4.5+ 立即投递 ｜ 4.0-4.4 值得投递 ｜ 3.5-3.9 有特殊理由才投 ｜ <3.5 不投。

## 公司类型与薪资可信度

公开薪资只是招聘信号，不等于合同固定薪资。解读薪资前先分类公司类型：

大厂/成熟科技（可信度高-中）→ 成长期创业（中）→ 早期初创（中-低）→ 传统企业（中）→ 外包/乙方（中-低）→ 本地中小企业（低）→ 销售提成型（低，除非 base 写清）→ 猎头代发（低-中）。品牌方与签约主体不同时，按**实际用工主体**分类。不确定则标 Unknown，可信度按"低"保守处理。

薪资可信度：**高**=明确固定 base 或有公开薪级；**中**=区间大体可信但组成未拆；**低**=数字可能含绩效/全勤/提成/"最高可达"。JD 有薪资数字时必须拆分：公开区间 / 可能的固定 base / 浮动部分 / 预计稳定到手 / 非现金福利。

## 中国大陆市场特性（评估必查）

| 概念 | 处理原则 |
|---|---|
| 五险一金 | 公积金比例（最高各12%）是薪酬包重要部分；对比灵活用工时需扣除 |
| 个税 | 3%-45% 累进；高总包必须给税后到手预估；注意年终奖单独计税 |
| 年终奖 | 核实是合同固定（如16薪）还是纯浮动绩效；总包=月薪×(12+预期年终月数) |
| 期权/RSU | 4年归属+1年cliff；初创期权评估兑现可能性；上市RSU视同现金但注意解禁税 |
| 试用期 | 1-6个月；工资不得低于正式的80%；确认是否全额+五险一金是否足额 |
| 竞业限制 | 红线风险项：范围是否过宽、期限（最长2年）、补偿金（≥离职前均薪30%）是否合规 |
| 校招 vs 社招 | 必须明确岗位类型，简历框架对齐 |
| 996/加班 | 文化信号关键扣分项；查加班费/调休是否落实 |
| 税前/税后 | Comp 评分默认税前对比市场，但必须提供税后预估 |
| 落户/人才补贴 | 深圳等地落户指标、人才补贴是加分项，计入文化/福利信号 |

## 全局规则

**严禁**：虚构经历或量化指标；直接修改母版简历源文件；代替候选人点击最终发送/投递按钮；话术中透露手机号等隐私；建议接受低于市场合理水平的薪资；未完整读取 JD 就生成简历；官腔空话；评估后不登记 tracker。

**必须**：评估前先读母版简历和 `[me]` 配置；识别岗位画像；匹配岗位要求时引用简历原文佐证；用 WebSearch 查市场薪酬与公司背景（裁员/冻编等）；评估后登记追踪；生成中文文本用自然地道的技术中文（短句、主动语态；stack/pipeline/embedding 等通用术语保留英文）。

**核心守则：无证据时沉默胜于编造。**

## 写作规则（外发文本通用）

- 忌陈词滥调："充满热情的"、"结果导向的"、"赋能"、"闭环"、"深厚行业背景"
- 细节优先于抽象："将 p95 延迟从 2.1s 降到 380ms" 远好于 "显著提升性能"
- 句式多样：列表不要以相同动词开头；长短句交替
- ATS 兼容：避免装饰性 Unicode 字符，普通 UTF-8 文本
- 若 `resume/writing-samples/` 存在写作样本，先提取候选人语气/句长/词汇偏好再模仿其口吻
