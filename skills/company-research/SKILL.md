# 公司深度研究（Deep Research）

> 改编自 career-ops `modes/deep.md`（MIT）。补入 job-copilot 模块 M9 前置步骤（原PRD缺口）。
> **先读 `skills/shared/求职共享上下文.md`**。

## 六个研究维度

1. **AI/技术战略**：产品的 AI 集成程度、技术栈构成、技术博客/公众号发文、论文与开源贡献
2. **近期动态**（近半年）：AI/工程岗位招聘节奏、收购、产品发布、融资公告、高管变动、**裁员与业务收缩新闻**
3. **工程文化**：发布频率、技术栈偏好、办公政策（远程/混合/995/996）、员工评价情绪
4. **可能面临的挑战**：扩展性瓶颈、可靠性/成本/延迟问题、基础设施迁移、员工评价中反复出现的抱怨——**这是面试叙事的金矿**（你能帮他们解决什么）
5. **竞争与差异化**：竞品地图、护城河、市场定位
6. **候选人切入角度**：把你的背景（母版简历）对到该公司的需求上——哪些项目最相关、面试叙事怎么讲

## 信息源（本土化）

| 用途 | 信息源 |
|---|---|
| 工商/股权/风险 | 天眼查、企查查（公开页） |
| 员工评价/内幕 | 脉脉、看准网 |
| 薪酬水位 | 职友集、看准、脉脉薪酬 |
| 融资/动态 | 36氪、IT桔子、公司官方公众号 |
| 技术文化 | 公司技术公众号/博客、GitHub org、掘金/知乎技术号 |
| 招聘节奏 | Boss直聘在招岗位数量与更新频率 |

## 输出

`reports/deep-{公司slug}-{YYYY-MM-DD}.md`：六维各一节，每节给**可操作的洞察**（不是资料堆砌）——直接服务于"投不投、怎么谈、面试讲什么"。结尾附"候选人切入角度"总结：3 个最相关项目 + 一段面试叙事草稿。
