# 简历排版制作（单页 · 匀称 · 美观）

> 对应 job-copilot 简历产出。红线：内容只重组母版简历真实经历，不虚构。

## 核心目标：内容与页面互相适应

一页简历最忌两种失衡：**内容溢出到第 2 页**（哪怕一行），或**内容挤在上半页、下方大片留白**。
目标是让**内容自然填满 A4 一页的可用区域**（约页高的 88–96%），上下呼吸均匀。

**量化校验**（生成后必做，两步）：
1. 测 `.page` 元素高度：A4 ≈ 1123px（96dpi, 297mm），目标 **1040–1110px（填充 93–99%）**。`<1000` 下方空太多→加间距/字号；接近/超 1123→收。
2. **用 pypdf 真数页数**（唯一可信）：`len(PdfReader(pdf).pages) == 1`。别只靠估算——曾出现"估算在页内、实际串页"。

**两个必踩的坑（务必规避）**：
- **别给 `.page` 设 `min-height: 297mm`**：它强制元素满一页，加任何尾部边距/亚像素就把总高顶过 1123px→串出几乎空白的第 2 页。用自然高度（不设 min-height），靠间距把内容撑到 ~96%。
- **末段/末项清零下边距**：`section:last-child{margin-bottom:0}`、`.item:last-child{margin-bottom:0}`，否则尾部 margin 累加溢出。

## 调节杠杆（内容少→放大呼吸，内容多→收紧）

| 杠杆 | 舒适区间 | 说明 |
|---|---|---|
| 正文 font-size | 10–11px | 单页信息量大时取小值 |
| line-height | 1.42–1.6 | 内容少时加大最省事、也最好看 |
| section 间距 | 9–18px | **填页留白的首选调节项** |
| item 间距 | 7–13px | |
| li 行距 | 2–4px | |
| 页边距 padding | 12–16mm | 内容少时加大边距比堆留白在底部好看 |

**优先级**：内容偏少时，先加 section/item 间距和 line-height（让全篇均匀舒展），再考虑加大页边距；**不要**靠底部单块留白凑页高。

## 结构与视觉层次

1. **页眉**：姓名（大、字间距宽）+ 求职意向（accent 色）+ 一行联系方式；**照片右上角**（证件照 5:7，约 88×123px，细边框圆角）。
2. **一句话概述**：accent 底色卡片，点明定位与最强能力，2 行内。
3. **正文顺序**（求 AI 岗）：项目经历（**倒序，近期在前**）→ 工作经历（倒序）→ 教育 → 技能。技术岗把项目提到工作前。
4. **每段**：标题行左（粗）右（日期，浅灰）对齐；要点用小圆点 + accent 加粗关键词/数字。
5. **配色**：单一 accent（如深青 #0d6e63）+ 墨色文字 + 浅灰辅助线；忌多色。
6. **数字与关键词高亮**：量化成果（40%、precision@10=80%）和硬技能用 accent 加粗，是扫读锚点。

## 制作流程

1. 从母版简历取真实内容，按目标岗位裁剪（可省略弱相关项，不可虚构）。
2. HTML+CSS 写版（`@page A4; margin:0`，`.page` 控 padding）。照片 base64 内嵌。
3. Playwright `page.pdf(format="A4", print_background=True)` 渲染。
4. **量正文底 y 坐标校验单页与比例**，按上表调间距逼近 1040–1110px。
5. 截图肉眼复核：无串页、上下均匀、层次清晰。
6. 照片如需"用完删除"，删原图与临时文件——照片已嵌在 PDF 内不丢。下次改版从旧 PDF 抠回（扫 JPEG 的 FFD8…FFD9）。
